# Slice 08 — Test Plan (`08-reports-variance`)

| Test ID | Layer | Scenario & Expected Result |
|---|---|---|
| `R01` | Application (`ReportTests`) | **Material Shortage Math & Hybrid UOM Normalization**: Open `Released`/`InProgress` orders in non-base UOM (`BOX` -> `PCS`) aggregate `RequiredBaseQuantity`, ignore `Draft`/`Completed`/`Cancelled` orders and `IsSubAssembly == true` lines, subtract `InventoryBalance.OnHandBaseQuantity`, and compute exact `ShortageBaseQuantity`, `ExcessBaseQuantity`, and `CoveragePercent`. |
| `R02` | Application (`ReportTests`) | **Production Consumption & Yield Variance with Reversal**: Order with planned input vs `ProductionIssue` + partial/full `Reversal` computes exact `IssuedBaseQuantity`, `VarianceBaseQuantity`, `RemainingToIssueBaseQuantity`, `ReceivedBaseQuantity`, and `YieldPercent` against `ActualProducedQuantity`. |
| `R03` | Application (`ReportTests`) | **Site Isolation**: Site A user cannot read or filter Site B shortage rows, variance orders, order details, or exports (`ReportingErrors.AccessDenied` / scoped results contain Site A only). |
| `R04` | Application (`ReportTests`) | **Authorization Separation (`Reports.Read` vs `Reports.Export`)**: User with `Reports.Read` only can view Shortage/Variance reports and order drill-downs, but `ExportMaterialShortageCsv` / `ExportProductionVarianceCsv` throws `ReportingRuleException(ReportingErrors.AccessDenied)`. |
| `R05` | Application (`ReportTests`) | **CSV Formula Injection & UTF-8 BOM**: Item names/notes starting with `=`, `+`, `-`, `@`, `\t`, or `\r`, plus commas/quotes, are prefixed with `'`, properly RFC-4180 quoted, and encoded with UTF-8 BOM (`EF BB BF`). |
| `R06` | Domain & Web Contracts (`RoleDomainTests`, `ResourceContractTests`) | `PermissionModule.Reports`, `Reports.Read`, `Reports.Export` exist in `PermissionCatalog`, are localized in `fa-IR`/`en-US`, mapped in `RolePermissionLocalization`, and all `/reports` resource keys match `ResourceContractTests`. |
| `S01` | Live SQL (`ReportSqlTests`) | End-to-end SQL flow: create `Unit`, `Item`, active `BomVersion`, `Warehouse`, post opening `Receipt`, `Release` & `Start` `ProductionOrder`, post `ProductionIssue` + `Reversal` + `ProductionReceipt`, record actual output, and verify `SqlReportingQueryStore` returns exact SQL shortage & variance numbers across normalized units. |
| `S02` | Live SQL (`ReportSqlTests`) | Multi-site SQL isolation: orders and balances in Site A and Site B are strictly separated when querying with Site A actor vs Site B filter. |
| `B01`–`B04` | Browser / UI Verification | Bilingual (`fa-IR` RTL + `en-US` LTR) desktop `1440px` & mobile `320px` rendering via `browser-check.cjs`, anonymous `/reports` redirect (`302`), `/account/login` (`200`), zero console/page errors, zero horizontal overflow. |
